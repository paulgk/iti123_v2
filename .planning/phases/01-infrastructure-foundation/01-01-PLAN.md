<task type="auto">
  <name>Task 1: Initialize Git LFS and configure tracking rules</name>
  <files>.gitattributes, .gitignore</files>
  <action>
1. Install Git LFS if not present: `git lfs install`
2. Create .gitattributes with LFS tracking for model files:
   - Track *.h5 files (Keras models)
   - Track *.pkl files in models/ directory only (not data/ pkl files)
   - Track *.onnx files (if future export)
   Pattern: `models/**/*.pkl filter=lfs diff=lfs merge=lfs -text`
   Pattern: `*.h5 filter=lfs diff=lfs merge=lfs -text`

3. Update .gitignore to exclude:
   - Video files: *.mp4, *.avi, *.mov, *.mkv
   - Large data: data/raw/**, raw_videos/**
   - Temporary: *.tmp, __pycache__/, .ipynb_checkpoints/
   - Keep existing ignores, add new rules at bottom with comment

Do NOT track videos with LFS (they go to GCS to avoid bandwidth trap).
Do NOT track data/processed/splits/*.pkl with LFS (too large, stays in GCS).
  </action>
  <verify>
- `git lfs track` shows .h5 and models/**/*.pkl tracked
- `cat .gitattributes` shows LFS patterns
- `cat .gitignore` includes *.mp4
  </verify>
  <done>Git LFS initialized, .gitattributes tracks model files, .gitignore excludes videos and large data files</done>

<task type="auto">
  <name>Task 2: Create configuration files for Colab infrastructure</name>
  <files>config/colab.yaml, config/paths.yaml, requirements-colab.txt</files>
  <action>
1. Create config/ directory: `mkdir -p config`

2. Create config/colab.yaml with Colab runtime settings:
```yaml
# Colab Enterprise Runtime Configuration
runtime:
  python_version: "3.10"
  accelerator: "GPU"  # T4 GPU default
  machine_type: "n1-standard-4"

session:
  # Auto-checkpoint to GCS on interruption
  checkpoint_interval_minutes: 30
  max_session_hours: 12

environment:
  # Force Python 3.10 in Colab (default is 3.12)
  setup_commands:
    - "apt-get update && apt-get install -y python3.10 python3.10-venv"
    - "python3.10 -m venv /content/venv"
    - "source /content/venv/bin/activate"
```

3. Create config/paths.yaml with path configuration:
```yaml
# Path Configuration for GCS and Local Storage
gcs:
  bucket: "iti123storage"  # User will customize
  videos_prefix: "videos/"
  features_prefix: "features/"
  models_prefix: "models/experiments/"
  checkpoints_prefix: "checkpoints/"
  mlflow_prefix: "mlflow/"

local:
  # Colab paths (ephemeral)
  colab_root: "/content"
  colab_data: "/content/data"
  colab_outputs: "/content/outputs"

  # Git repo paths (persistent via git)
  repo_data: "data/"
  repo_models: "models/"
  repo_outputs: "outputs/"
  repo_features: "data/processed/features/"

sync:
  # Files to pull from GCS at session start
  pull_patterns:
    - "videos/*.mp4"
    - "features/*.pkl"
  # Files to push to GCS at session end
  push_patterns:
    - "outputs/**"
    - "checkpoints/**"
```

4. Create requirements-colab.txt with pinned Colab dependencies:
```
# Colab Enterprise Dependencies (Python 3.10)
# Install with: pip install -r requirements-colab.txt

# Core ML - pinned for compatibility
tensorflow==2.15.0
mediapipe==0.10.9
protobuf==3.20.3

# Data processing
numpy>=1.24.0,<2.0.0
pandas>=2.0.0
scipy>=1.10.0
scikit-learn>=1.3.0

# Visualization
matplotlib>=3.7.0
seaborn>=0.12.0

# Experiment tracking
mlflow>=2.7.0

# GCS access
google-cloud-storage>=2.10.0

# Utilities
tqdm>=4.65.0
pyyaml>=6.0.0
python-dotenv>=1.0.0

# Video processing
opencv-python>=4.8.0
```

Note: This is separate from requirements.txt to isolate Colab-specific versions.
  </action>
