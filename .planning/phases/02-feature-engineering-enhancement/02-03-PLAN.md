  <name>Task 1: Implement angular velocity features (FEAT-05)</name>
  <files>src/data_processing/angular_velocity_features.py</files>
  <action>
Create angular velocity feature extraction module with PROPER NOISE HANDLING.

CRITICAL: Angular velocity calculation is noise-sensitive. MediaPipe pose jitter amplifies through differentiation. MUST smooth at multiple stages.

1. **extract_angular_velocity_features(pose_sequence, fps=30):**

   Pipeline (smooth-differentiate-smooth):
   a. Smooth positions with gaussian_filter1d (sigma=1.5)
   b. Calculate joint angles from smoothed positions
   c. Smooth angles with gaussian_filter1d (sigma=1.0)
   d. Differentiate smoothed angles to get angular velocity
   e. Clip to realistic bounds (< 5000 deg/s for human joints)

   Joint angles to track:
   - Elbow angle (shoulder-elbow-wrist)
   - Shoulder angle (elbow-shoulder-hip)
   - Forearm rotation (angle of forearm vector in sagittal plane)

   Output features:
   ```python
   {
       # Elbow extension velocity
       'elbow_extension_vel_max': float,      # Max extension speed (deg/s)
       'elbow_extension_vel_median': float,   # Median (robust to noise)
       'elbow_extension_peak_timing': float,  # Normalized 0-1

       # Forearm rotation velocity
       'forearm_rotation_vel_max': float,     # Peak rotation speed
       'forearm_rotation_vel_range': float,   # Total rotation range

       # Quality indicator
       'angular_velocity_quality': str,       # 'ok' or 'suspect_noise'
   }
   ```

2. **calculate_angle_3d(p1, p2, p3):**
   Utility function (may already exist in v2, reuse if so):
   - Calculate 3D angle at p2 formed by vectors p1-p2 and p3-p2
   - Return degrees (not radians)

3. **validate_angular_velocity(velocities):**
   - Check for unrealistic values (> 5000 deg/s)
   - Check for noise domination (std > 3 * abs(median))
   - Return quality assessment

Research reference values (elite badminton):
- Forearm rotation: 800-1200 deg/s during forward swing
- Elbow extension: 400-800 deg/s

Use robust statistics (median, percentiles) instead of mean to reduce noise impact.
