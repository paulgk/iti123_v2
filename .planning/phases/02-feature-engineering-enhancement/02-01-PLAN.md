  <action>
Create phase segmentation module with velocity-based detection:

1. **segment_stroke_phases(pose_sequence, fps=30):**
   - Extract wrist positions from pose_sequence (landmark 15 for right-handed)
   - Smooth positions with gaussian_filter1d (sigma=1.5)
   - Calculate velocity magnitude from smoothed positions
   - Detect contact frame as peak velocity (NOT peak position - critical)
   - Use scipy.signal.find_peaks for phase transition detection:
     - height: velocity > 30% of mean
     - distance: min 5 frames between peaks
     - prominence: 0.5 * std(velocity)
   - Identify backswing_start as first significant peak before contact
   - Calculate forward_swing_start: max(backswing_start + 3, contact - 35% of sequence)
   - Return dict with phase boundaries (frame indices)

2. **detect_contact_frame(pose_sequence):**
   - Focused function for contact frame detection only
   - Returns single frame index at peak velocity
   - Include validation: contact should be in 30-80% of sequence

3. **get_intent_window(contact_frame):**
   - Return frame range [contact-5 : contact-2] for intent analysis
   - This is the most discriminative window per coaching insights

4. **MediaPipe landmark constants:**
   - LANDMARKS dict with joint indices (from v2)
   - Support for right/left handed detection (mirror X for left-handed)

Use scipy imports:
```python
from scipy.signal import find_peaks
from scipy.ndimage import gaussian_filter1d
```

Do NOT use fixed percentage boundaries (outdated approach).
