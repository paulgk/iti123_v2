  <files>src/data_processing/feature_selection.py</files>
  <action>
Create feature selection module with filter methods:

1. **calculate_cohens_d(feature_values, labels):**
   Calculate Cohen's d effect size for binary classification:
   ```python
   pooled_std = sqrt(((n0-1)*var0 + (n1-1)*var1) / (n0+n1-2))
   cohens_d = (mean1 - mean0) / pooled_std
   ```

   Return dict:
   ```python
   {
       'cohens_d': float,
       'abs_d': float,
       'interpretation': str,  # 'negligible'/'small'/'medium'/'large'
       'meets_criteria': bool  # abs_d >= 0.5
   }
   ```

   Interpretation thresholds (biomechanics standard):
   - negligible: d < 0.2
   - small: 0.2 <= d < 0.5
   - medium: 0.5 <= d < 0.8 (SUCCESS CRITERIA threshold)
   - large: d >= 0.8

2. **filter_by_effect_size(X, y, threshold=0.5):**
   - Calculate Cohen's d for each feature
   - Return list of features meeting threshold
   - Log effect size distribution (count per category)

3. **calculate_vif(X):**
   Use statsmodels variance_inflation_factor:
   ```python
   from statsmodels.stats.outliers_influence import variance_inflation_factor
   ```

   VIF interpretation:
   - VIF < 5: low multicollinearity (ideal)
   - 5 <= VIF < 10: moderate (acceptable)
   - VIF >= 10: high (remove feature)

4. **filter_by_vif(X, threshold=10):**
   Iteratively remove highest VIF feature until all VIF < threshold:
   ```python
   while True:
       vif_scores = [variance_inflation_factor(X.values, i) for i in range(len(X.columns))]
       max_vif = max(vif_scores)
       if max_vif < threshold:
           break
       worst_idx = vif_scores.index(max_vif)
       X = X.drop(columns=[X.columns[worst_idx]])
   return X.columns.tolist()
   ```

   Log removed features and their VIF scores for analysis.

5. **filter_zero_variance(X):**
   - Remove features with variance < 1e-8
   - Return remaining feature names

Handle edge cases:
- Empty feature set after filtering: raise ValueError with helpful message
- Single feature remaining: skip VIF (not applicable)

  <action>
Add wrapper method and combined pipeline:

1. **rfecv_selection(X, y, max_features=254):**
   Use sklearn RFECV for cross-validated feature selection:

   ```python
   from sklearn.feature_selection import RFECV
   from sklearn.ensemble import RandomForestClassifier

   estimator = RandomForestClassifier(
       n_estimators=100,
       max_depth=10,
       min_samples_split=10,
       random_state=42
   )

   selector = RFECV(
       estimator=estimator,
       step=1,
       cv=5,
       scoring='f1',
       min_features_to_select=max(10, int(max_features * 0.5)),
       n_jobs=-1
   )
   ```

   If RFECV selects > max_features, take top max_features by ranking.

   Return:
   ```python
   {
       'selected_features': list,
       'n_features_optimal': int,
       'cv_scores': array,
       'feature_ranking': dict  # feature -> rank
   }
   ```

2. **feature_selection_pipeline(X, y, target_features=254):**
   Full two-stage pipeline:

   Stage 1 (Filter):
   a. Remove zero-variance features
   b. Filter by Cohen's d >= 0.5
   c. Filter by VIF < 10

   Stage 2 (Wrapper):
   d. Apply RFECV on filtered features
   e. Ensure count <= target_features

   Return:
   ```python
   {
       'selected_features': list,
       'stages': {
           'initial': int,
           'after_zero_var': int,
           'after_cohens_d': int,
           'after_vif': int,
           'after_rfecv': int
       },
       'effect_sizes': dict,      # feature -> Cohen's d
       'vif_removed': list,       # features removed by VIF
       'rfecv_ranking': dict,     # feature -> rank
       'cv_f1_score': float       # best CV F1
   }
   ```

3. **save_feature_selection_mask(selected_features, output_path):**
   Save selected feature names to JSON for use by feature_engineering_v3:
   ```python
   {
       'version': 'v3',
       'selected_features': [...],
       'selection_date': '2026-01-30',
       'n_features': int,
       'selection_method': 'filter_then_wrapper'
   }
   ```

   Default output_path: 'data/processed/features_v3/selected_features.json'
   This populates the manifest used by Plan 05.

IMPORTANT: Filter methods MUST run before wrapper methods. Wrapper on 658 features with 3,347 samples = overfitting guaranteed. Filter reduces to ~200-300 features first, making wrapper feasible.
